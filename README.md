# SalesScope – Sales Analytics Dashboard 📊

SalesScope is an interactive sales analytics website built using HTML, CSS, JavaScript, and Chart.js. It helps users explore sales performance through key metrics, visualizations, and interactive filters.

## ✨ Features

- **KPI Summary:** View total revenue, total orders, average order value, and units sold.
- **Sales Trends:** Visualize monthly revenue and profit using a line chart.
- **Product Analysis:** Compare revenue across product categories.
- **Regional Analysis:** Explore regional sales distribution using a doughnut chart.
- **Interactive Filters:** Filter sales records by category, region, and time period.
- **Order Records:** Search and explore order-level data.
- **Business Insights:** Identify the leading product category, region, and month based on revenue.

## 🛠️ Tech Stack

- CSS3
- JavaScript
- Chart.js

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/shashanki-hub/SalesScope-Sales-Analytics-Dashboard.git
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or run it using the Live Server extension.
4. Ensure you have an internet connection for the Chart.js CDN if the library is loaded externally.

## 📈 Dataset

The dashboard currently uses illustrative e-commerce sales data defined in JavaScript. The dataset contains 20 sample orders across multiple product categories and four sales regions, covering January to June 2026.

The figures are for demonstration purposes and do not represent actual business transactions.
